## 🛠️ Technology Ecosystem

- **Frontend**: React 18, Vite 8, Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons & Graphics**: Lucide React, Official Brand SVG Ecosystem (Devicon)
- **Deployment & CI/CD**: GitHub Pages, GitHub Actions (`.github/workflows/deploy.yml`)
- **Architecture**: Modular functional components, centralized data store (`portfolioData.js`), responsive design across desktop, tablet, and mobile.

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/Anubha-create/Personal-portfolio.git
cd Personal-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
